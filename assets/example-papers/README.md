# Example papers

Essays for local end-to-end testing of the marker. Third-party essays are
**copyrighted** and are gitignored: they stay on your machine and are not committed.

| File | Source | Committed |
|------|--------|-----------|

to Markdown, following [`skills/prepare-essays`](../../skills/prepare-essays/SKILL.md).
Then add it to `.gitignore`.
